# Code of conduct

Aven is open to everyone. So that anyone can take part with peace of mind, we
commit to:

- **being respectful**, in issues, pull requests, reviews and everywhere else;
- **criticising code, not people**, with arguments and examples;
- **welcoming beginners**: no question is a stupid one;
- **harassing no one**: no insults, discriminatory remarks, threats, unwanted
  attention or sharing of private information;
- **staying on topic**: no spam, no advertising.

This code applies to every space of the project and to anyone who represents
Aven there.

## Reporting a problem

If someone does not respect this code, contact the maintainers privately
through a GitHub report, or the contact shown on the repository's profile.
Every report is handled discreetly. Maintainers may remove a message, refuse a
contribution, or exclude someone from the project, for a time or for good.
